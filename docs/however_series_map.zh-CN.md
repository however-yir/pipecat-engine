# however 系列仓库地图

| 仓库 | 角色 | 说明 |
|---|---|---|
| `pipecat-engine` | 语音与多模态智能体框架发行版 | 实时对话 pipeline、服务接入与工程化治理 |
| `autonomous-driving-lab` | 自动驾驶开源栈集成实验室 | ROS2/Autoware、Vehicle Signals、DLT 与仿真实验的证据化归档 |
| `embedded-systems-lab` | 嵌入式系统实验室 | 固件构建、串口日志、网页监控与边缘设备验证材料 |
| `agents` | AI Agent 底层工具链 | 子项目 demo、风险控制、审计日志与检索能力样例 |

## 关系说明

1. `pipecat-engine` 关注 AI Agent 实时交互与工程可维护性，包发布名保留 `howeverpipecat-ai`。
2. 自动驾驶与嵌入式仓库属于并行技术线，文档可互相借鉴，但代码与依赖独立。
3. 仓库名优先使用当前 GitHub 实体名称，避免把旧发行代号误认为仍在维护的独立仓库。
